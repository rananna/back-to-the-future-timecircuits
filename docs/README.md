# 📚 Time Circuits Documentation

Welcome to the official documentation for the Back to the Future Time Circuits Replica project. This page is the central hub for all guides, references, and tutorials.

## 🚀 Getting Started

If you're new to the project, start here. This section will guide you through the entire process of building and installing the firmware for your Time Circuits replica.

-   **[Hardware & Pinout Guide](getting-started/hardware.md)**: A complete list of required components and the official wiring diagram.
-   **[Firmware Installation Guide](getting-started/installation.md)**: Step-by-step instructions for compiling and flashing the firmware onto your ESP32.
-   **[Firmware Update Guide](getting-started/updating.md)**: How to update your device to the latest firmware version.

## 📖 User Guide

This section is for users who have a working Time Circuits clock and want to learn how to use its features.

-   **[Web Interface Guide](user-guide/web-interface.md)**: A complete tour of the web UI for configuration and control.
-   **[Home Assistant Integration](user-guide/home-assistant.md)**: A detailed guide on integrating with Home Assistant, including powerful Blueprints for easy automation.
-   **[Sound System Guide](user-guide/sound-system.md)**: A guide to the sound system, including playing sound effects, internet radio, and Text-to-Speech (TTS).
-   **[Troubleshooting Guide](user-guide/troubleshooting.md)**: Solutions to common problems and frequently asked questions.
