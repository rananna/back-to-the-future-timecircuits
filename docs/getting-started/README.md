# Getting Started Guide

Welcome to the Time Circuits project! This guide provides a complete, step-by-step path to building your own replica.

## The 3 Steps to Success

Building and maintaining your Time Circuits clock involves three main stages.

### **Step 1: The Build**
This is the main hardware and software phase, where you'll gather your components, assemble the physical device, and flash the firmware for the first time.

*   **[Bill of Materials](./bill-of-materials.md)**: A complete list of all the components you'll need.
*   **[Wiring Guide](./wiring.md)**: A guide to wiring all the components together.
*   **[Assembly Guide](./assembly.md)**: A guide to assembling the 3D printed case.
*   **[Firmware Installation](./firmware-installation.md)**: A guide to installing the firmware.

### **Step 2: The Setup**
This is the final configuration phase, where you'll connect the clock to your network and learn how to use it.

*   **[First-Time WiFi Setup](./wifi-setup.md)**: Learn how to connect your new clock to your home WiFi network.
*   **[Web Interface Guide](../user-guide/web-interface.md)**: Take a complete tour of the web UI to configure all your clock's settings and features.

### **Step 3: Updating**
This guide shows you how to update your device's firmware and web interface after the initial setup.

*   **[Updating Guide](./updating.md)**: Learn how to update the firmware and web interface using the built-in web updater.

---

> 🎉 **Once you've completed these steps, your Time Circuits clock will be fully operational!**
>
> After that, you can explore the **[User Guides](../user-guide/README.md)** to learn about more advanced features, like Home Assistant integration.
